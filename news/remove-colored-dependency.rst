**Removed:**

* Remove ``colored`` from Gooey's dependencies. Gooey no longer uses it, so installing Gooey no longer installs ``colored``. Programs that import ``colored`` will fail with ``ModuleNotFoundError: No module named 'colored'`` on a fresh install. To fix this, add ``colored`` to your program's requirements or run ``pip install colored``. The rich text console still styles output from ``colored`` 1.x and 2.x.
