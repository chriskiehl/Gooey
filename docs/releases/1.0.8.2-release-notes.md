## Gooey 1.0.8.2 Released! 


A small maintenance release focused on getting Gooey running cleanly on modern Python and wxPython. Gooey now officially supports Python 3.9 through 3.14 and works with wxPython 4.3 / wxWidgets 3.3. This release also rolls up a batch of community translation contributions that had been waiting in the queue.


### Python version support 

Python 2 support has been formally dropped. `setup.py` now declares `python_requires='>=3.9'` and lists classifiers for Python 3.9–3.14. Users who still need Python 2 should pin an older release (`pip install Gooey==1.0.4`) and install wxPython manually, as described in the README.

As part of this cleanup, `wxpython>=4.1.0` is now always included in the install requirements, and the unused `dependency_links` entry has been removed from `setup()`.


### Python 3.14 / wxPython 4.3 compatibility fixes 

 * Fixed: `GooeyParser` instances can now be passed as `parents=[...]` to another `GooeyParser` on Python 3.14. 
 * Fixed: ANSI color codes from Python 3.14's colorized argparse output no longer leak into subparser `prog` strings (and thus into the UI). 
 * Fixed: mutually exclusive groups on `GooeyParser` are now created against the underlying `ArgumentParser`. 
 * Fixed: `Dropdown` no longer tries to restore an invalid selection index when its choices are updated, which raised errors on wxPython 4.3. 
 * Fixed: the time-remaining timer now passes an explicit interval, which is required by wxWidgets 3.3.

### Other Fixes / Changes: 

 * Dependencies: pin `colored` to `>=1.3.93,<2`, to avoid incompatibilities with the 2.x series. 
 * Dependencies: removed the use of `six` (replaced with `sys.maxsize`), so it is not a required dependency. 
 * Use raw strings for regexes to suppress invalid escape sequence warnings (Ben Elliston). 
 * Docs: README and contributor docs updated to reflect the removal of Python 2 support. 
 * Tests: numerous fixes to the test suite so it runs reliably on current Python/wxPython, including fixing test methods that returned values, destroying the macOS dock icon between test iterations, freeing reused control IDs in the test harness, and new tests for parent inheritance and rich-console/ANSI handling. 


## Breaking Changes 

**No breaking API changes from 1.0.8.1 to 1.0.8.2.** However, Python versions earlier than 3.9 are no longer supported.
